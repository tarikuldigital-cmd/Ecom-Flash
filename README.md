# Ecom-Flash

A modern eCommerce operations SaaS starter built with Next.js, TypeScript and Recharts.

## Getting started

1. Install Node.js 20.9+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Included in this starter

- Responsive commerce operations dashboard
- Revenue analytics chart
- Order fulfillment overview
- Recent orders table with search
- Responsive sidebar navigation

## Planned modules

Order management, products, inventory, warehouse, courier integrations, COD reconciliation, purchasing, suppliers, analytics, team permissions, billing and subscriptions.

## Current limitations

This is an initial frontend starter using sample data. Authentication, database persistence, payments, courier APIs, and production authorization are not implemented yet.
